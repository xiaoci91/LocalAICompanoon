# Local AI Companion - Minecraft Fabric AI同伴模组

本地离线大模型驱动的AI生存同伴模组，专为Minecraft 1.20.1 Fabric设计。

## 特点

- **完全本地运行**：所有AI计算都在你的电脑上完成，不需要联网
- **安全沙箱**：多层权限控制，保护你的存档不被AI破坏
- **硬件自适应**：从4G显存到16G+显存都能跑，还有纯CPU模式
- **持久记忆**：AI同伴会记住你说过的话，不会聊几句就忘
- **双运行模式**：生存队友模式 / 角色扮演聊天模式
- **自动探测**：自动识别本地Ollama/LM-Studio服务
- **主动对话**：AI有独立思想，会主动挑起话题，不会原地发呆
- **语音合成**：支持 Edge TTS 语音，AI说话有声音
- **自定义皮肤**：支持切换 Steve/Alex 皮肤
- **AI同伴背包**：右键打开AI的物品栏，27格存储空间
- **生存助手**：能砍树、挖矿、打怪，帮你干活
- **双模式切换**：生存队友模式 / 角色扮演聊天模式，一键切换

## 前置要求

1. **Minecraft 1.20.1** + **Fabric Loader**
2. **Fabric API** 0.88.1+
3. **本地大模型服务**（任选其一）：
   - [Ollama](https://ollama.com/)（推荐，最简单）
   - [LM Studio](https://lmstudio.ai/)
   - llama.cpp
   - 任何兼容OpenAI API格式的本地服务

> ⚠️ 本模组不包含大模型权重文件，需要你自己安装本地AI服务。

## 快速开始

### 第一步：安装Ollama（推荐）

1. 去 [ollama.com](https://ollama.com/) 下载安装Ollama
2. 打开命令行，输入：
   ```bash
   ollama pull qwen2:7b-instruct-q4_K_M
   ```
3. 等待模型下载完成（约4GB）

### 第二步：安装模组

1. 把 `LocalAICompanion.jar` 放到你的 `.minecraft/mods` 文件夹
2. 确保已经安装了 Fabric API
3. 启动游戏

### 第三步：召唤AI同伴

1. 进入游戏，创建一个新世界
2. 输入命令：`/companion summon`
3. AI同伴就会出现在你身边！
4. 试试对它说话：`@小艾 你好` 或者 `/ai 你好`

## 硬件预设选择指南

根据你的电脑配置选择合适的预设：

| 预设档位 | 推荐配置 | 模型 | 显存占用 | 推荐指数 |
|---------|---------|------|---------|---------|
| **最低4G显存** | GTX 1650 / RTX 3050 4G | qwen2:7b-instruct-q2_K | ~3.5GB | ⭐⭐ |
| **CPU纯运行** | 没有独立显卡 | qwen2:7b-instruct-q2_K | 内存8GB+ | ⭐ |
| **通用6-8G显存（默认）** | RTX 3060 8G / RTX 4060 | qwen2:7b-instruct-q4_K_M | ~5GB | ⭐⭐⭐⭐⭐ |
| **12G显存高配** | RTX 3060 12G / RTX 4070 | qwen2:7b-instruct-q4_K_M | ~5GB | ⭐⭐⭐⭐ |
| **16G以上高性能** | RTX 4080 / RTX 4090 | qwen2:14b-instruct-q4_K_M | ~9GB | ⭐⭐⭐⭐⭐ |
| **云端API模式** | 不需要显卡 | 自行填写 | - | ⭐⭐⭐ |

### 怎么改预设？

1. 按 **R键** 打开AI同伴面板
2. 点击「LLM设置」
3. 点击「硬件预设」按钮循环切换
4. 选好后点「保存设置」

## 使用说明

### 基本操作

| 操作 | 方式 |
|------|------|
| 召唤同伴 | `/companion summon` |
| 解散同伴 | `/companion dismiss` |
| 和同伴说话 | `@小艾 你要说的话` 或 `/ai 你要说的话` |
| 打开背包 | 右键点击AI同伴 |
| 打开面板 | 按R键 |
| 查看状态 | `/companion status` |

### 你可以让AI做什么

### 模式切换

按 **R键** 打开面板，点击「切换到聊天模式」/「切换到生存模式」按钮即可切换：

- **生存队友模式**：AI可以帮你干活（挖矿、砍树、打怪）
- **角色扮演聊天模式**：AI只能聊天和跟着你，不能修改世界

### 生存队友模式能做什么

- 「跟着我」- 跟随玩家
- 「过来」- 到你身边
- 「去挖10个铁矿」- 采集指定数量的矿石
- 「砍树」- 砍木头
- 「打怪物」- 攻击附近的怪物
- 「停下」- 停止当前任务
- 「你有什么」- 查看背包

### AI同伴背包

右键点击AI同伴可以打开它的物品栏：
- 27格存储空间（3行）
- 可以放工具、食物、材料
- AI挖矿砍树获得的物品会自动放进背包
- 死亡后背包物品会掉落（可配置）

### 角色扮演聊天模式

- 只能聊天和跟随
- 不能破坏方块、不能打怪
- 纯粹的聊天伙伴
- 适合角色扮演、讲故事

### 记忆系统

AI同伴会记住重要的事情：
- 你说「记住XXX」，它就会记下来
- 你的名字、喜好、重要地点
- 死亡、解散后记忆不会丢失
- 可以在「记忆管理」里查看和编辑

### 外观设置

支持自定义AI同伴的皮肤：
- 按 **R键** 打开面板 → 「外观设置」
- 支持 Steve（粗手臂）和 Alex（细手臂）两种皮肤
- 切换后重新召唤即可生效

### 语音功能（Edge TTS）

支持本地 Edge TTS 语音合成，AI说话有声音：
- 需要先启动 Edge TTS 语音服务（见下方说明）
- 按 **R键** 打开面板 → 「语音设置」
- 可自定义服务地址、语音名称、语速
- 支持测试语音功能

### 主动对话/独立思想

AI同伴不是只会被动回答，它有自己的思想：
- 每隔 1-2 分钟会主动说话，挑起话题
- 空闲时会随机走动，不会原地发呆
- 会评论环境、问你在做什么、提醒你注意危险
- 只有生存/冒险模式才会主动说话，创造模式不会

## 安全设置

### 权限开关（默认高安全）

| 权限 | 默认状态 | 说明 |
|------|---------|------|
| 破坏方块 | ❌ 关闭 | 允许AI挖方块 |
| 放置方块 | ❌ 关闭 | 允许AI放方块 |
| 采集矿石 | ❌ 关闭 | 允许AI挖矿 |
| 开启箱子 | ❌ 关闭 | 允许AI打开你的箱子 |
| 拾取物品 | ✅ 开启 | 允许AI捡东西 |
| 攻击怪物 | ✅ 开启 | 允许AI打怪 |
| 攻击动物 | ❌ 关闭 | 允许AI打动物 |
| 攻击玩家 | ❌ 绝对禁止 | 永远不会开启 |

> ⚠️ 开启高风险权限前，请确认你信任AI同伴的行为。

### 危险环境检测

AI会自动检测危险环境并紧急撤离：
- 岩浆 ✅
- 火焰 ✅
- 虚空 ✅

### 方块黑名单

默认保护以下方块不会被AI破坏：
- 所有箱子、潜影盒、木桶
- 所有熔炉、高炉、烟熏炉
- 所有床
- 所有门、活板门
- 附魔台、铁砧、信标
- 酿造台、炼药锅
- 命令方块
- 蜂巢、蜂箱
- 重生锚、潮涌核心
- ...等等60+种

## Edge TTS 语音服务

本模组支持对接本地 Edge TTS 语音服务，实现AI语音合成。

### 启动语音服务

1. 确保你有 Python 环境
2. 安装依赖：
   ```bash
   pip install edge-tts flask
   ```
3. 运行服务：
   ```bash
   python server.py
   ```
4. 服务默认运行在 `http://localhost:8880`

### 可用语音

支持多种中文语音：
- **女声**：xiaoxiao（晓晓，默认）、xiaoyi（小艺）、xiaomeng（晓梦）、xiaohan（晓涵）等
- **男声**：yunxi（云希）、yunyang（云扬）、yunjian（云健）等
- **方言**：东北话、北京话、粤语、台湾腔等

### 在模组中启用

1. 按 **R键** 打开面板
2. 点击「语音设置」
3. 开启语音功能
4. 填写服务地址（默认 `http://localhost:8880`）
5. 选择喜欢的语音
6. 点击「测试语音」测试效果

## 常见问题

### Q: AI不回我话怎么办？

A: 检查以下几点：
1. Ollama启动了吗？命令行输入 `ollama list` 看看
2. 模型下载了吗？输入 `ollama pull qwen2:7b-instruct-q4_K_M`
3. API地址对吗？默认是 `http://localhost:11434`
4. 按R键打开面板，点「测试连接」

### Q: 显存不够怎么办？

A: 换更小的模型：
1. 按R键 → LLM设置
2. 硬件预设切换到「最低4G显存」
3. 或者手动把模型改成 `qwen2:7b-instruct-q2_K`

### Q: 回答太慢怎么办？

A: 
1. 换更小量化的模型（q2_K比q4_K快）
2. 减小上下文窗口大小
3. 减小最大输出token数

### Q: AI乱挖东西怎么办？

A: 
1. 权限默认都是关闭的，检查你是不是手动开了
2. 在安全权限里关掉「允许破坏方块」
3. 添加安全区域保护你的基地

### Q: 支持多人服务器吗？

A: 
- 单人游戏 ✅ 完全支持
- 局域网联机 ✅ 支持
- 公网服务器 ⚠️ 部分支持（只有聊天和跟随，不能改世界）

### Q: AI怎么不说话/没有语音？

A: 检查以下几点：
1. Edge TTS 服务启动了吗？浏览器打开 `http://localhost:8880` 看看
2. 语音功能开启了吗？按R键 → 语音设置 → 开启
3. 服务地址对吗？默认是 `http://localhost:8880`
4. 点「测试语音」试试能不能听到声音

### Q: AI怎么不主动说话？

A: 检查以下几点：
1. 你是在生存/冒险模式吗？创造模式AI不会主动说话
2. LLM服务正常吗？AI能不能正常回复你
3. 耐心等一下，主动对话间隔是 1-2 分钟
4. AI有任务在忙的时候不会主动说话

### Q: 怎么换皮肤？

A: 
1. 按R键打开面板
2. 点击「外观设置」
3. 点击按钮切换 Steve/Alex 皮肤
4. 重新召唤AI同伴即可生效

## 配置文件位置

所有配置都保存在你的存档目录下：
```
.minecraft/saves/你的世界名/local_ai_companion/
├── long_term_memory.json    # 长期记忆
├── chat_history.json        # 聊天历史
├── safe_zones.json          # 安全区域
└── ...
```

全局配置在：
```
.minecraft/config/localaicompanion/
├── main_config.json
├── llm_config.json
└── permission_config.json
```

## 技术架构

四层隔离架构，从根源保证安全：

```
┌─────────────────────────────────┐
│  第1层：游戏实体表现层           │  ← 只处理显示和交互
│  (实体、渲染、GUI、事件)        │
├─────────────────────────────────┤
│  第2层：意图解析安全校验层       │  ← 核心安全层
│  (JSON解析、权限校验、黑名单)   │
├─────────────────────────────────┤
│  第3层：任务调度管理层           │  ← 状态机管理
│  (任务队列、超时、重试)         │
├─────────────────────────────────┤
│  第4层：LLM网络客户端层         │  ← 纯网络通信
│  (HTTP请求、限流、容错)         │
└─────────────────────────────────┘
```
